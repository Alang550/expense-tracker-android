# Expense Tracker

A personalized Android application to manage your finances. Track your income and expenses, visualize your spending patterns, and stay on top of your budget.

## Features

- **Income & Expense Tracking:** Log your financial activities with custom categories.
- **Visual Analytics:** Interactive charts to analyze your spending habits over time.
- **Local Persistence:** Securely stores your data on-device using Room.
- **Clean Architecture:** Built with Jetpack Compose, Hilt, and MVVM principles.

## Tech Stack

- **Jetpack Compose:** Declarative UI toolkit.
- **Room:** SQLite object mapping library.
- **Dagger Hilt:** Dependency injection.
- **Kotlin Coroutines:** Asynchronous programming.
- **MPAndroidChart:** Charting library.

## How to Run

1. Open the project in Android Studio.
2. Ensure you have the Android SDK (API 34) installed.
3. Sync Gradle and run the `:app` module on an emulator or device.
